========================================================
                WEBSITE SPECIFICATION
========================================================

Project Name: My Hub Website

Project Type: Multi-page personal interest website built with HTML, CSS, and JavaScript.

========================================================
1. OVERVIEW
========================================================

The website is a personal hub that allows users to explore
multiple interests through separate themed pages.

The website includes:
- A homepage hub
- A Minecraft page
- An Archery page
- An Infinite/Math-themed page
- Background music controls
- Interactive quiz system
- Animated visual effects
- Embedded videos
- Shared styling across all pages

The design uses a modern gradient-based aesthetic with
rounded cards, glowing effects, and interactive buttons.

3. Embedded Infinity Video

   - Glowing animated border effect

========================================================
4. AUDIO SYSTEM
========================================================

File:
music.js

Purpose:
Provides shared background music functionality across
all pages.

Features:
- Playlist system
- Persistent playback state
- Persistent mute state
- Shared synchronization between tabs
- Autoplay handling
- Dynamic mute/unmute SVG icons

Storage System:
Uses localStorage for:
- Current track index
- Playback time
- Mute state

Audio Controls:
- Floating mute button
- Bottom-left fixed position
- SVG icon updates dynamically

Playlist Behavior:
- Automatically advances tracks
- Loops playlist continuously

========================================================
5. QUIZ SYSTEM
========================================================

File:
quiz.js

Purpose:
Provides an interactive trivia experience.

Features:
- Question database
- Multiple categories
- Live score system
- Correct/incorrect styling
- End summary screen
- Restart support

Core Functions:
- buildFlatBank()
- updateHeaderTitle()
- loadQuizQuestion()
- handleAnswerSelection()
- showEndScreen()
- resetQuiz()

Question Flow:
1. Load question
2. User selects answer
3. Show feedback
4. Update score
5. Continue to next question
6. Show final summary
